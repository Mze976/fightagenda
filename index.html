Administration

Connexion sécurisée requise pour gérer le catalogue.
Aucun mot de passe par défaut n'est fourni dans le code. Configure les identifiants dans Supabase et dans les variables secrètes du dépôt avant publication. Ne publie jamais de mot de passe administrateur dans le frontend.
